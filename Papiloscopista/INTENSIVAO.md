## Revisão de Informática em uma página

| Ponto | Grave isto |
|---|---|
| Hardware | Parte física: dispositivos, componentes e periféricos. |
| Periférico de entrada | Envia dados ao computador: teclado, mouse, scanner, microfone. |
| Periférico de saída | Apresenta dados ao usuário: monitor, impressora, caixa de som. |
| Entrada/saída | Lê e grava ou recebe e envia: pendrive, tela touch, multifuncional, modem. |
| RAM | Memória principal, volátil, usada durante a execução. |
| ROM/firmware | Guarda instruções permanentes de inicialização ou controle. |
| SSD/HD | Armazenamento de massa, não volátil. |
| Backup | Cópia de segurança; pode ser local, externo ou em nuvem. |

## Pegadinhas rápidas

- SSD não é RAM.
- CPU não é periférico.
- Scanner é entrada; impressora é saída; multifuncional é entrada/saída.
- Menor desperdício em capacidade exige calcular antes de comparar.
- HTTPS é o protocolo seguro da Web; HTTP sozinho não indica criptografia.
