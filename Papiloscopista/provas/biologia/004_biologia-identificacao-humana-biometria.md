<p><strong>Resposta: E.</strong> Questão autoral no padrão FGV; não é reprodução literal de caderno oficial.</p>
<p><strong>Como pensar:</strong> A distinção FGV provável é identificação versus autenticação.</p>

<ul class="quiz-explain">
<li><strong>A.</strong> Incorreta. Isso descreve verificação 1:1.</li>
<li><strong>B.</strong> Incorreta. Sistemas biométricos podem ter falso positivo.</li>
<li><strong>C.</strong> Incorreta. Biometria usa característica física ou comportamental.</li>
<li><strong>D.</strong> Incorreta. Senha não é biometria.</li>
<li><strong>E.</strong> Correta. Busca 1:N tenta identificar na base.</li>
</ul>
<p><strong>Pegadinha principal:</strong> Misturar autenticação com identificação.</p>

<p><strong>2. Em sistema biométrico, falso positivo ocorre quando:</strong></p>
<div class="quiz-options">
<label class="quiz-option"><input type="radio" name="fgv-070" value="A"> A. o sistema rejeita corretamente um impostor.</label>
<label class="quiz-option"><input type="radio" name="fgv-070" value="B"> B. a câmera melhora a nitidez da imagem.</label>
<label class="quiz-option"><input type="radio" name="fgv-070" value="C"> C. a senha é trocada pelo usuário legítimo.</label>
<label class="quiz-option"><input type="radio" name="fgv-070" value="D"> D. o cadastro é excluído por ordem regular.</label>
<label class="quiz-option"><input type="radio" name="fgv-070" value="E"> E. o sistema aceita indevidamente uma pessoa como se fosse outra ou como autorizada.</label>
</div>
<button class="quiz-check" type="button">Checar resposta</button>
<div class="quiz-feedback" hidden>
<p><strong>Resposta: E.</strong> Questão autoral no padrão FGV; não é reprodução literal de caderno oficial.</p>
<p><strong>Como pensar:</strong> Separe falso positivo de falso negativo: aceitar indevidamente ou rejeitar indevidamente.</p>
<p><strong>Por que a alternativa correta está certa:</strong> Falso positivo é aceitação equivocada.</p>
<ul class="quiz-explain">
<li><strong>A.</strong> Incorreta. Rejeitar impostor é comportamento correto.</li>
<li><strong>B.</strong> Incorreta. Nitidez é qualidade de captura.</li>
<li><strong>C.</strong> Incorreta. Troca de senha não é erro biométrico.</li>
<li><strong>D.</strong> Incorreta. Exclusão regular de cadastro não é falso positivo.</li>
<li><strong>E.</strong> Correta. Aceitação indevida caracteriza falso positivo.</li>
</ul>
<p><strong>Pegadinha principal:</strong> Confundir erro de aceitação com erro de rejeição.</p>
