<p><strong>Resposta: B.</strong> Fonte: FGV SEAD/AP Papiloscopista 2022, questão 53. Gabarito oficial: B.</p>
<p><strong>Como pensar:</strong> Avalie cada afirmação separadamente com o Princípio de Le Chatelier: catalisador nunca desloca equilíbrio (só acelera); aumento de pressão desloca para o lado com menos mols de gás; diminuição de temperatura desloca para o lado exotérmico.</p>
<p><strong>Por que a B deve ser marcada:</strong> I é falsa (catalisador não muda rendimento). II é verdadeira: 4 mols de CO(g) viram 1 mol de Ni(CO)₄(g), então aumento de pressão favorece o lado com menos mols de gás, consumindo CO. III é falsa: a reação direta é endotérmica (ΔH positivo), então diminuir a temperatura desloca para o lado exotérmico, ou seja, para o sentido inverso, não o direto.</p>
<ul class="quiz-explain">
<li><strong>A.</strong> <strong>Não marque.</strong> I é falsa: catalisador não altera rendimento.</li>
<li><strong>B.</strong> <strong>Deve ser marcada.</strong> Apenas II é verdadeira.</li>
<li><strong>C.</strong> <strong>Não marque.</strong> III é falsa: diminuir temperatura desloca para o sentido inverso (exotérmico), não o direto.</li>
<li><strong>D.</strong> <strong>Não marque.</strong> I é falsa.</li>
<li><strong>E.</strong> <strong>Não marque.</strong> I e III são falsas.</li>
</ul>
<p><strong>Pegadinha principal:</strong> Achar que catalisador aumenta rendimento, ou inverter o sentido do deslocamento por temperatura numa reação endotérmica.</p>

<p><strong>Como pensar:</strong> I é direta (ambos ΔH negativos = exotérmicos). Para II e III, use a Lei de Hess: a entalpia de combustão de CO a CO₂ é ΔH₁-ΔH₂=-890-(-607)=-283 kJ/mol.</p>
<p><strong>Por que a D deve ser marcada:</strong> I é verdadeira. II é falsa: a combustão parcial (a CO) libera 607 kJ, não 890 kJ (890 é da combustão completa, a CO₂). III é verdadeira: combustão de CO a CO₂ libera 283 kJ/mol; para 5 mols, 5×283=1415 kJ.</p>
<ul class="quiz-explain">
<li><strong>A.</strong> <strong>Não marque.</strong> Ignora que III também é verdadeira.</li>

<li><strong>C.</strong> <strong>Não marque.</strong> Ignora que I também é verdadeira.</li>

<li><strong>E.</strong> <strong>Não marque.</strong> II é falsa.</li>
</ul>
<p><strong>Pegadinha principal:</strong> Usar diretamente o ΔH₁ (-890 kJ) para a combustão parcial de metano, sem perceber que esse valor corresponde à combustão completa (a CO₂), não à parcial (a CO, que corresponde a ΔH₂=-607 kJ).</p>
